# BrainCell v0.4.0 release checklist

Do not publish, tag, or create the GitHub Release until PyPI trusted publishing
is configured.

## PyPI trusted publisher

Create the pending trusted publisher on PyPI with these exact fields:

- Project: `braincell-mcp`
- Owner: `kt2saint-sec`
- Repository: `braincell`
- Workflow: `publish.yml`
- Environment: `pypi`

The release workflow uses PyPI OIDC trusted publishing. Do not add API tokens or
repository secrets for package upload.

## Optional TestPyPI dry run

If using TestPyPI first, configure the equivalent trusted publisher for the test
project and run the release workflow against TestPyPI from a disposable test tag
or manual workflow path. Verify the package installs in a clean environment
before deleting the test tag.

## Tag and GitHub Release

Create the `v0.4.0` tag and GitHub Release only after the trusted publisher is
configured. The tag-triggered `publish.yml` workflow must complete successfully
before announcing the release.

## Post-publish verification

After PyPI publication completes:

```bash
pipx install braincell-mcp==0.4.0
braincell --help
braincell setup . --dry-run --client codex
```
