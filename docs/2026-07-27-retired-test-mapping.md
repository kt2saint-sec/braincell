project-only contract and the replacement assertions now carried by the same
modules. No mapped test file was deleted, skipped, or xfailed.

During the rewrite, valid default `braincell recall` and `braincell search`
calls exposed a production defect: both CLI handlers still forwarded the
removed `scope=` keyword. The handlers now pass the resolved connected Project
ULID instead; the positive CLI tests fail if this binding regresses.
